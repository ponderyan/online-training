## API 端点

|------|------|------|

| DELETE | /api/org-codes/abbreviations/:id | 删除词条 |
| GET | /api/org-codes/rules | 读取编码规则 |
| PUT | /api/org-codes/rules | 更新编码规则 |
| GET | /api/org-codes/preview?parentId=&name= | 实时预览 |

## 编码生成策略

1. 查父组织 code（若 include_level=true）
2. 名称匹配词典：精确 > 包含 > 英文提取 > 兜底
3. 拼接：父code + 分隔符 + 缩写
4. 截断 20 位 + 大写
5. 查重：冲突追加数字后缀

## 注意事项

- 已有编码不受配置变更影响
- auto_generate 可关闭回退手动模式
- 自动生成跳过格式正则（父编码可能数字开头）
- schema 同步使用 prisma db push
